## Project Utama

### 1. LALOTOURISM

Jenis: Sistem Informasi Pariwisata / Project Akademik  
Role: Web Developer  
Tahun: 2023  
Live Preview: https://sinchangm24.github.io/LaloTourism/

#### Ringkasan

LALOTOURISM adalah sistem informasi pariwisata berbasis web untuk membantu memperkenalkan destinasi wisata di Labuhan Lombok kepada masyarakat dan wisatawan.

#### Konteks Project

Project akademik berkelompok ini diawali dengan wawancara dan observasi untuk memahami kebutuhan penyebaran informasi wisata. Kebutuhan tersebut diterjemahkan menjadi struktur informasi, fitur sistem, dan website dinamis.

#### Masalah

Website wisata perlu menampilkan informasi destinasi dan berita secara lebih rapi, serta memiliki cara sederhana untuk mengelola konten.

#### Kontribusi Saya

- Mengerjakan tampilan halaman website menggunakan HTML dan CSS.
- Melakukan wawancara dan observasi untuk mengidentifikasi kebutuhan informasi wisata.
- Mengerjakan fitur CRUD untuk berita dan tempat wisata.
- Membantu mengubah halaman HTML statis menjadi PHP dinamis.
- Menghubungkan website dengan database MySQL menggunakan XAMPP.
- Membuat alur dasar admin untuk mengelola konten website.

#### Output

- Halaman website dapat mengambil konten dari database.
- Admin memiliki alur dasar untuk mengelola data berita dan destinasi.
- Project memiliki live preview publik sebagai bukti tampilan awal website.

#### Hasil

Project ini menghasilkan website wisata sederhana dengan alur frontend, backend, database, dan admin dasar.

#### Yang Saya Pelajari

Dari project ini saya belajar dasar fullstack web: membuat tampilan, menghubungkan database, membuat CRUD, dan memahami bagaimana konten bisa dikelola dari sisi admin.

#### Teknologi

HTML, CSS, JavaScript, PHP, MySQL, Figma, CRUD
